# QuizPro — Quizizz-style

## Что внутри
- регистрация и вход;
- 25 вопросов по теме «Қазақ мәдениеті»;
- подсчёт результата из 25;
- общий рейтинг;
- Top 3 после завершения;
- Express-сервер и сессии;
- адаптивный интерфейс.

## Запуск в VS Code

1. Откройте папку `quizpro_quizizz` в VS Code.
2. Откройте Terminal → New Terminal.
3. Выполните:

```bash
npm install
npm start
```

4. Откройте в браузере:
http://localhost:3000

## Важно про общий рейтинг

Сейчас пользователи и результаты хранятся в памяти запущенного Node.js сервера. Это удобно для демонстрации и локальной работы, но после перезапуска сервера данные сбрасываются.

Чтобы реально дать ссылку другим студентам и сохранить общий рейтинг в интернете, нужно подключить постоянную БД (например PostgreSQL/Supabase) и разместить сервер на хостинге. Архитектура проекта уже разделена на frontend и backend, поэтому это можно добавить следующим этапом.
